# Tableau × Excelデータ分析を効率化！

VSCodeで動くGUI付きPython前処理ツール

## はじめに

こんにちは、**TechCommitメンバーの友季子**です。
Tableauに渡す前のExcel整形で時間がかかっていませんか？本記事では、**GUIでクリックするだけ**で「空行/空列削除・重複除去・欠損値処理・型変換・フィルタ・列名変更・Excel/CSV出力」まで完了できる**前処理ツール**を紹介します。

---

## 1. 概要（できること）

* **データクリーニング**：空行/空列削除、重複行削除、欠損値処理（削除・0埋め・前方埋め・カスタム値）
* **データ変換**：テキスト整形（前後空白・連続空白の正規化）、型変換（数値/日付の自動化）、列名変更、条件フィルタ
* **エクスポート**：Excel（.xlsx）/ CSV で保存
* **安心設計**：元データ保持、**リセット**相当のやり直し、ステータスで実行結果が確認可能

### 2.1 上部タイトルバー

* **「Tableau Excel前処理ツール」**：ツール名。中央のサブタイトルに「ExcelをTableau分析向けに…」と目的を表示。

### 2.2 右側：データプレビューパネル

* **読み込んだデータを表形式で表示**します。列ヘッダとスクロールバー付きで、行・列を確認可能。
* 例では「年 / 月 / 売り上げ / メール（例：[yuki@gmail.com](mailto:yuki@gmail.com)）」などが表示。
* **処理を実行すると即時反映**されるため、操作結果を目視で確認できます。

### 2.3 左側：操作パネル（上から順番に）

#### (A) ファイル操作

* **📂 ファイル選択**：Excel/CSV を選択して読み込み。複数シートのExcelは既定シート（通常は先頭）を読み込み。
* **🔄 再読み込み**：同じファイルを読み直します。列名や型の再判定をやり直したいときに使用。

#### (B) データ概要

* **件数/列数/空行/空列/重複行/メモリ使用量**など、品質チェックに必要な数値を表示。
* **列情報**：主要な列名と推定データ型（例：`int64`, `float64`, `object` など）が確認できます。
* ここを見れば、\*\*前処理の優先度（空行が多い／重複が多い等）\*\*をすぐ判断できます。

#### (C) データクリーニング

* **空行削除**：全列がNaN/空白の行を一括削除。
* **空列削除**：全行がNaN/空白の列を一括削除。
* **重複行削除**：完全一致の重複レコードを除去（先勝ち保持）。
* **欠損値処理**：ダイアログで方式を選択

  * 削除 / 0埋め / 前方埋め（前の値で補完）/ カスタム値入力
  * **対象列の選択**も可能（全列一括も可）

#### (D) データ変換

* **テキスト整形**：前後の空白を除去し、連続スペースを1つに正規化。

  * 例：「` Tokyo   Branch`」→「`Tokyo Branch`」
* **型変換**：文字列から **数値/日付** を自動判定して変換。Tableau取り込み時の型エラーを予防。
* **列名変更**：ダイアログで旧→新の列名を入力し、**一括・個別**で変更可能。
* **データフィルタ**：列・条件（=, ≠, >, <, in, not in など）・値を指定して取り出し。

  * 例：「売り上げ > 100」「地域 in \[Tokyo, Osaka]」

#### (E) データ出力

* **🟩 データを保存する**：現在のデータを保持状態に反映（内部キャッシュ更新）。
* **Excel保存（.xlsx）**：`openpyxl` でテーブルを保存。
* **CSV保存（.csv）**：UTF-8（BOM付き/なしは環境設定に準拠）で保存。

#### (F) 補助

* **ボタン有効化**：処理中に無効化されたボタンを再度アクティブ化。
* **状態確認**：直近の実行ログやメッセージを表示（例：「Excel保存完了」）。

### 2.4 画面下部：ステータスバー

* **処理結果のメッセージ**を表示します（例：`Excel保存完了`）。
* 保存や削除、フィルタなど**各操作の成功/失敗が一目で分かる**ので、作業の抜け漏れを防げます。

## 3. 使い方（手順）

### 3.1 起動

```bash
cd desktop\excel
python tableau_preprocessor_gui.py
```

### 3.2 基本フロー

1. **📂ファイル選択**でExcel/CSVを読み込む
2. **データ概要**を見て、空行・重複・欠損の有無を把握
3. **データクリーニング**（空行/空列/重複/欠損）を上から順に実行
4. **データ変換**（テキスト整形→型変換→列名変更→必要ならフィルタ）
5. **🟩データを保存する**で内部確定
6. **Excel保存 / CSV保存**で出力し、Tableauへ投入

> **コツ**：
>
> * クリーニング → 変換 → フィルタ → 保存/出力 の順が最短です。
> * 途中で気になったら**再読み込み**→やり直しもOK。

## 4. コードでの利用方法（シンプル版のみ）

GUIの内部機能は\*\*`TableauDataPreprocessor`クラス\*\*としても利用できます。

```python
from tableau_preprocessor import TableauDataPreprocessor

# 1) インスタンス化（読み込み）
processor = TableauDataPreprocessor("your_data.xlsx")

# 2) 概要確認
processor.show_data_info()
processor.preview_data()

# 3) 基本クリーニング
processor.remove_empty_rows()
processor.remove_duplicates()
processor.clean_text_data()
processor.convert_data_types()

# 4) 保存（Tableau用に最終出力）
processor.create_tableau_extract("clean_data.xlsx")
```

## 6. よくある質問（トラブルシュート）

* **Q. `tkinter`が見つからない**
  A. 公式サイト版のPythonを再インストールして、`tcl/tk`が含まれていることを確認。Anaconda系なら `conda install tk` を実行。

* **Q. Excel保存で警告が出る**
  A. `openpyxl`が必要です。`pip install openpyxl` を再確認。ファイルが開きっぱなしの場合は閉じてから保存してください。

* **Q. 文字化けする**（CSV）
  A. WindowsのExcelで開く場合は **UTF-8(BOM付き)** が安全です。保存時のオプションをBOM付きに設定してください。
